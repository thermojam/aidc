# Служебная информация: частичная нативная проверка

27 ноября 2026, macOS 27.2.1 (26B131), arm64. Нативный WebKit, debug-сборка `AIDC Service UX QA`, отдельный новый синтетический профиль, конфигурация окна 900×650. Исходная проверка клавиатуры выполнена также в ранее запущенной `AIDC Error UX QA` с отдельным тестовым профилем. Сценарий использовал `local-mock`, без платного POST. Размер окна указан по конфигурации, фактические размеры не измерялись.

| Критерий задачи 04 | Результат |
| --- | --- |
| Одна строка на 1280 px и уменьшение высоты | Не проверено: нет парных снимков и измерений одинакового состояния до и после. |
| Компактное окно: блокировки, перенос и отсутствие горизонтальной прокрутки | Не проверено. При 900×650 показана краткая строка `Тест · без сети · local-mock`, но геометрия и блокировки не измерялись. |
| Клавиатура, фокус и объявление статуса | Частично: после проверки Tab достигает «Состав запроса», Enter раскрывает, пробел закрывает; дерево доступности показывает сохранение фокуса на заголовке. В исходной сборке отдельный контур фокуса не был различим; после добавления стиля он виден в новой сборке. Однократность объявления VoiceOver не проверена. |

| Раскрытие и позиция истории при потоке | Не проверено в этой сборке. Предыдущие наблюдения прокрутки в `checks.md` относятся к другим сборкам и не являются приёмкой этого изменения. |
| Снимки и границы | Парные снимки одинаковых состояний до и после отсутствуют. Проверка запроса проводилась только на тестовом транспорте; реальные Ollama и SimpleClaw, Windows и VoiceOver не проверялись. |
