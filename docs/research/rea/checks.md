## Продолжение A5 и локальный срез A6 — 6 ноября 2026

- **A5, кэш и категории:** Rust-тест запросил каталог по недоступному локальному адресу: ошибка не изменила сохранённый снимок, пользовательская категория осталась в SQLite. В отдельном запущенном тестовом профиле macOS кэш содержал 4 снимка; после запуска той же `.app` с недоступным HTTPS-прокси осталось 4 снимка, последний `fetched_at=1793946883`, `integrity_check=ok`. Это подтверждает сохранность кэша в таком сценарии; сообщение об ошибке и выбор категории в окне не проверены, поскольку инструмент UI не привязался к тестовой сборке. Ручные категории «Мышление / Скорость / Экономия» хранятся отдельно от каталога с источником `user` и временем; исходное состояние — «Остальные».
- **A6, код:** Rust добавил явный HTTP POST с ключом из Keychain, текстовым сохранённым контекстом, SSE-парсером и Channel. Код не делает автоматический повтор POST. HTTP-статус, безопасные серверные ID, код ошибки и доступный `usage` сохраняются с попыткой; отсутствие `usage` остаётся неизвестным. UI показывает выбор модели, состояние ключа, стоимость из каталога и предупреждение перед платным Retry. Миграции схемы доведены до `user_version=6`.
- **Проверено без платного API на macOS:** локальный синтетический HTTP-сервер дал `[DONE]` и `usage` — попытка завершилась с одним сохранённым текстом; EOF без конца сохранил частичный текст как `interrupted`; HTTP 429 сохранил код ошибки как `failed`; отмена после дельты дала `stopped`. `cargo test --offline`: 24 теста, 23 прошли, 1 нативный Keychain-тест пропущен; локальный сервер потребовал запуска тестов вне песочницы. `npm run build` и тестовая macOS `.app` собраны. Финальная тестовая `.app` запущена на профиле со схемой версии 5: после старта `user_version=6`, `integrity_check=ok`, `foreign_key_check=0`, кэш каталога сохранился.
- **Открыто после локального среза:** тестовая `.app` не дала инструменту UI привязаться к окну; новые команды не проверены из viewer при исполнении. Windows не проверялась. До отдельного разрешения платных POST в этом срезе не было; результат последующей разрешённой пробы указан ниже.

**Один разрешённый платный POST через Rust-клиент A6, macOS, 6 ноября 2026:** публичный `GET /v1/models` вернул HTTP 200, 42 модели; для `gpt-oss-20b` опубликованы 6,6 ₽/млн входных и 33 ₽/млн выходных токенов. Короткий синтетический запрос отправлен один раз через `run_http_stream` с ключом, временно записанным и затем удалённым из отдельной записи Keychain. Получены HTTP 200, три текстовые дельты, терминальный `[DONE]`, статус `completed`, 8 байт ответа, серверные `request_b046068e-326d-4987-b3d8-e956fa269c17` и `chatcmpl_8feafcb1-480c-457d-a116-7be757986817`. Серверный `usage`: 100 входных, 104 выходных, всего 204 токена. Фактическое списание не подтверждено финансовым показателем сервера; его нельзя вычислять как факт из каталога. Повтора POST не было. Это один успешный transcript, не полный контракт обрыва, отмены и тарификации; отправка нажатием в окне приложения остаётся непроверенной. Значение ключа не выводилось.
