## Реализация

Подключены Tailwind 4.3.5 и его Vite-плагин без Preflight. Используются только адаптированные Shadcn Button, NativeSelect и Dialog на Radix 1.3.1. Нет второй семьи примитивов, удалённых ресурсов и новых оконных полномочий. Версии закреплены; сравнение package-lock с исходным commit подтвердило отсутствие изменений версий существующих пакетов. Лицензии и источники — в [THIRD_PARTY_NOTICES.md](../../../../THIRD_PARTY_NOTICES.md).

Цвета определены в `src/style.css`, утилиты ссылаются на смысловые переменные. Настройки используют 32 px контролы и диалог с радиусом 8 px. Исторические Int UI/Islands и компактный чат обозначены предыдущей стадией в DESIGN.md и ui-refresh.md. Компоновка остальных областей не переносилась.

`public/theme-init.js` — локальный блокирующий script в head перед React. Он разрешает сохранённый `appearance` в `data-theme=light/dark` до появления React-экрана. React сохраняет прежние значения `system/light/dark` под тем же ключом; при системном выборе подписывается на изменение `prefers-color-scheme`. CSP основного окна не менялась.

## Измерения и автоматические проверки

`python3 scripts/check-theme-contrast.py` рассчитывает относительную яркость sRGB по WCAG и контраст реальных значений CSS-токенов. [contrast.json](contrast.json) содержит 64 пары без ошибок. Минимумы:

| Роль | Светлая | Тёмная | Требование |
| --- | --- | --- | --- |
| Основной текст | 13,963:1 | 10,634:1 | ≥4,5 |
| Вторичный текст / placeholder | 6,092:1 | 4,858:1 | ≥4,5 |
| Текст primary, normal/hover | 6,362:1 | 4,908:1 | ≥4,5 |
| Граница контрола | 3,210:1 | 3,408:1 | ≥3 |
| Фокус | 5,014:1 | 5,980:1 | ≥3 |

Слабый `--border` используется для декоративных разделителей, не как единственный контур поля. Disabled не входит в измерения активных контролов. Расчёт не измеряет все пиксели JPEG или ещё не перенесённые области интерфейса.

Начальный script дополнительно выполнен в Node VM до React: шесть случаев — сохранённые light/dark вопреки теме ОС, system при обеих темах, отсутствие ключа и неизвестное значение. Во всех случаях `data-theme` совпал с ожидаемым.

`npm run typecheck`, `npm run build` (в том числе перед обеими `.app`) прошли. Полный `cargo test --offline`: 46 успешно, 2 штатно пропущены (платный POST и нативный Keychain). Предупреждение Vite о чанке более 500 КБ осталось. Линтер и отдельный frontend test runner в проекте не настроены; Rust/IPC/БД этим изменением не менялись.

Windows, macOS 13, 200% масштаб, VoiceOver и полный сценарий backup/restore в новом диалоге не проверялись. Более ранние результаты не заменяют эти проверки; общий редизайн и P0 не объявлены готовыми.
