- [Конфигурация нативной проверки](native-config.json): отдельный идентификатор и профиль, окно 1280×850. Разрешение `core:webview:allow-set-webview-zoom` и hotkeys добавлены только в эту тестовую конфигурацию; продуктовая capability и CSP не изменены. Пять нажатий Cmd+= от исходного масштаба дают 200%, ещё одно — 220%; Cmd+0 возвращает 100%.
- [Одноразовый сценарий Chromium](smoke.mjs): прошёл 11 ноября до исправлений, найденных нативной проверкой и ревью. Запускается из временного каталога с Playwright, при Vite на 127.0.0.1:1423; проект не получил новой тестовой инфраструктуры или зависимости. Подмена IPC использует только синтетические данные. Сценарий проверяет действия и ширины документа, но не измеряет геометрию модальной панели; успешный прогон не доказывает её правильное нативное положение.

Нативный запуск использовал `HTTPS_PROXY=http://127.0.0.1:1`, тестовые проекты и беседы. Ключи, личная история и платные POST не использовались. Снимки — реальные кадры WKWebView, не макеты. Физический размер окна во время проверки масштаба оставался прежним; результат не выдаётся за проверку физического resize.
