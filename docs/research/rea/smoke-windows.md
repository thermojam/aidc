# Windows 10/11 x64: локальный smoke-тест

Этот сценарий нужно выполнить **на реальной Windows-машине**. Сборка на macOS или CI его не заменяет.

1. Установить Node.js 22 LTS, Rust stable с MSVC toolchain, Visual Studio C++ Build Tools и WebView2 Runtime по [инструкции Tauri](https://v2.tauri.app/start/prerequisites/). Записать версии Windows, WebView2, Rust и Node.
2. В чистой копии репозитория выполнить `npm ci`, `npm run build`, затем в `src-tauri` выполнить `cargo test`.
3. В корне выполнить `npm run tauri dev`. Убедиться, что открылось главное окно и текст говорит, что запросы в сеть не отправляются.
4. Отправить `Тест Windows`. Убедиться, что ответ появляется частями, итог равен `Локальный тестовый ответ на: Тест Windows`, а статус завершённый.
5. Отправить длинный текст и нажать «Остановить» во время потока. Убедиться, что частичный ответ остался со статусом `stopped`.
6. Закрыть приложение и запустить снова. Убедиться, что оба ответа сохранились и нет повторной генерации.
7. Во время третьего потока завершить процесс приложения через диспетчер задач. Запустить снова; частичный ответ должен иметь статус `interrupted`.
8. Выполнить `npm run tauri dev -- --config src-tauri/tauri.viewer-test.conf.json`. В окне `IPC boundary test` должен появиться текст `PASS: все три команды отклонены`; в истории не должно появиться сообщение `viewer must fail`.
9. Записать фактические результаты и ошибки в `checks.md`.

Использовать только синтетические сообщения. Ключ SimpleClaw не нужен.
