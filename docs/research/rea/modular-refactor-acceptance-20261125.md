# Модульный рефакторинг: состояние приёмки на macOS

Дата: 25 ноября 2026. Исходная точка `48dfcb1`, проверенный коммит приложения `43dfea6`, ветка `develop`. Рабочая копия содержит незакоммиченные изменения, включая расширение `src/viewer.ts`; результат отрицательного теста ниже относится к этой рабочей копии. Это промежуточный отчёт: обязательные проверки A1–A8 ещё не все завершены, общая приёмка не закрыта. Windows исключена из текущей работы по решению пользователя и не проверялась.

## Карта переносов

- `main.tsx` → `App.tsx` для координации и `main.tsx` для монтирования; `index.html` по-прежнему загружает `main.tsx`.
- Изображения → `features/images/useImageGeneration.ts`, `ImageGenerationView.tsx`; состояние принадлежит постоянно смонтированному `App` через хук.
- Голос → `features/voice/useVoiceInput.ts`; задачи и уведомления → `features/tasks/useScheduledTasks.ts`, `TasksView.tsx`.
- Поле ввода → `features/composer/MessageComposer.tsx`; поток и повтор → `features/chat/useChatGeneration.ts`.
- Внутренние операции Artifacts → `src-tauri/src/artifacts.rs`; внешние команды оставлены в `lib.rs`. Подробная карта последующих Rust-срезов — в [журнале](checks.md).

## Входы и ресурсы

Vite собирает `index.html` и `viewer.html`, которые указывают на существующие `src/main.tsx` и `src/viewer.ts`. Существующие импорты тестов разрешаются сборкой и тестами. Все 20 ссылок `include_str!`/`include_bytes!` в `lib.rs` указывают на существующие файлы. Относительные Markdown-ссылки проверены в `README.md`, `docs/research/rea/README.md`, `spec.md` и спецификации модульного рефакторинга; отсутствующих целей не найдено. Конфигурация viewer создаёт отдельное окно, а capability `main` разрешает команды только окну `main`. Исторические записи не переписывались.

Для повтора viewer использована команда `npm run tauri build -- --debug --bundles app --config /private/tmp/aidc-accept-viewer-20261125.json`: конфигурация задавала отдельные `productName` и `identifier`, окно `main` и окно `viewer` с URL `viewer.html`. Файл конфигурации находится во временном каталоге и при новом запуске его нужно создать заново; расширение `src/viewer.ts` в проверенной рабочей копии не входит в `43dfea6`.

Следующие проверки на macOS: копия синтетического профиля предыдущей сборки с реальными точками ветвления; повторные сквозные сценарии A3–A6 на итоговом коде; сравнение широкой и узкой компоновки и клавиатурный доступ к ошибкам A8. Реальный платный POST и системный Keychain не запускались в итоговом прогоне.

## Дополнение: проверка итогового кода на macOS

Из `48dfcb1` командой `git archive` собрана отдельная debug `.app` с новым идентификатором и пустым профилем. В ней отправлен локальный тестовый запрос и повторён ответ: интерфейс показал «Ответ 1» и «Ответ 2». Копия базы создана через SQLite backup и помещена в отдельный профиль `.app`, собранной из текущей рабочей копии приложения `43dfea6` (в ней также присутствует незакоммиченное расширение viewer). Беседа и обе ветки открылись, переключение на первый ответ сработало. Этот профиль не содержал вложений или Artifacts: их совместимость в том же дорефакторном профиле остаётся открытой.

Для изображений, голоса и задач создана отдельная диагностическая сборка из `43dfea6`. В ней команда генерации изображения заменена запросом к локальному HTTP-серверу; вызов распознавания заменён фиксированной строкой, проверка ключа на кнопке отключена; при создании профиля добавлены синтетические задачи и результат, в обработчик уведомлений добавлен счётчик. Рабочий код и реальные ключи не менялись. Локальный сервер вернул PNG после задержки: при ожидании элементы запроса были заблокированы, после перехода в чат и обратно результат появился, а файл, сохранённый через системный диалог, совпал побайтно с ответом сервера. Журнал сервера содержит запрос с текстом `Synthetic local image final QA`. Реальный сетевой путь и проверка тарифа Rust этой подменой не проверены.

В той же диагностической сборке началась запись микрофона, после остановки показана запись 8,1 с. Диалог подтверждения появился; вместо отправки аудио подставлен `Synthetic transcription 742`, который один раз добавился к тексту `Draft QA` и исчез из панели. Реальное распознавание не проверялось. На экране задач открывался синтетический результат; уведомления включались и затем выключены, расписание остановлено. Надёжно связать одно нажатие именно системного уведомления о результате с одним срабатыванием обработчика в этом прогоне не удалось.

Платных POST в этом дополнении не было. Сборки выполняли `npm run build` с проверкой TypeScript; итоговый и исходный интерфейсы запускались с конфигурациями 900×650 и 1200×800, но фактические размеры окон пока не измерены.

Для сравнения пустого чата отдельно собраны исходная и итоговая версии с параметрами окна 600×650 и 1200×800. В узком окне обе версии скрыли боковую панель, оставили навигацию и настройки в заголовке, перенесли кнопки проверки и отправки на новую строку. В обеих видна внутренняя прокрутка поля ввода, а его нижняя строка частично скрыта у нижней границы окна; это наблюдалось и до рефакторинга. В конфигурации 1200×800 обе версии показали боковую панель и кнопки в одной строке, заметных различий пустого экрана не обнаружено. Фактические размеры окон отдельно не измерялись, поэтому 1200×800 — запрошенный, а не подтверждённый размер. Динамические состояния и все диалоги в обоих размерах не сравнивались.
