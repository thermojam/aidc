Он **не** подтверждает запуск перечисленных сценариев и не раскрывает полную защиту приложения. Поставленный `webview` целиком не разобран. ## План реализации

Самый короткий путь к полезному продукту — довести текущий P0 и расширять его по реальным пользовательским сценариям. Перенос всей архитектуры Codex целиком не нужен для локального чата. Каждый следующий этап открывается после проверяемого результата предыдущего.

| Шаг | Что сделать в этом репозитории | Проверяемый результат |
|---|---|---|
| 0. Закрыть P0 | Пройти незакрытые сценарии `checks.md`: работающая macOS `.app`, длинные ответы, ошибки, темы, файлы и фокус; подписанный пакет; отдельная реальная Windows; отрицательные проверки статического Preview. | Установка и ключ работают на двух ОС, запрет viewer проверен, реальный поток и восстановление подтверждены. Интерактивный режим остаётся выключенным до собственных испытаний. |
| 1. Несколько бесед | Добавить `conversations` и простой список: создать, выбрать, переименовать, архивировать; привязать сообщения, попытки, вложения и Artifacts к беседе. | Две беседы независимы; после перезапуска, миграции и backup/restore ни одна не смешивается и не теряется. |
| 2. Проекты и материалы | Сгруппировать беседы в локальные проекты; вначале оставить явный выбор файлов, затем добавить ограниченный просмотр папки и поддерживаемые типы. Не индексировать весь диск по умолчанию. | Пользователь видит точный состав отправляемого контекста; выбранные файлы не меняются тайно; секретные и большие файлы отклоняются или требуют явного действия. |
| 3. Агентный протокол | Перед инструментами ввести в Rust модель шага: текст модели → предложение действия → разрешение → результат → следующий шаг; хранить журнал и состояние незавершённого шага. Проверить, что SimpleClaw действительно поддерживает нужный tool-calling для выбранных моделей. | Синтетический агент завершает многошаговую задачу, переживает перезапуск, не удваивает платный POST и не выполняет действие до разрешения. |
| 4. Локальные инструменты | Добавить чтение/поиск в выбранной папке, затем запись патча и команды; отдельный процесс с ограничением файлов/сети, лимитами времени и вывода. Не передавать ключ модели инструментам. | Отрицательные тесты выхода за папку, симлинков, сети, секретов и вызова из viewer проходят на macOS и Windows. |
| 5. Git и проверка | Показывать diff, комментарии и результаты тестов; затем управляемые worktree и перенос задачи между средами. | Два агента меняют независимые копии; пользователь видит точные изменения, может принять/отклонить их, основной checkout не меняется без действия пользователя. |
| 6. Расширения | После устойчивого агента добавлять навыки, MCP, браузер, расписание, голос, удалённый доступ и облако отдельными решениями. | У каждой интеграции есть собственные права, журнал действий, отзыв доступа и испытания на целевых ОС. |

Перед шагом 3 нужно принять отдельное решение: строить собственный агентный цикл поверх SimpleClaw или подключить готовый совместимый runtime. Это зависит от проверенного API, лицензии и модели безопасности. До этого решения можно полностью выполнить шаги 0–2. Для P2 нельзя считать обычный Tauri WebView песочницей для команд или недоверенного HTML. Платные проверки API требуют нового разрешения на конкретный расход согласно правилам репозитория.

## Что осталось неизвестным

1. Полная экранная инвентаризация Codex 26.1103.31037 в чистом профиле: локально не запускалась, личные данные не читались.
2. Связь экранов и внутренних модулей текущей поставки: REA-разбор ограничен выбранными файлами, а полный граф `webview` не построен.
3. Доступность функций по конкретному аккаунту и платформе: официальная документация описывает продукт, а не права этой установки.
4. Совместимость SimpleClaw с агентным циклом для конкретных моделей, надёжное возобновление и фактическое списание при обрыве: документация и локальные тесты P0 не закрывают эти вопросы.
