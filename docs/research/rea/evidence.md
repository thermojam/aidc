# Доказательства и сравнение

## Граница наблюдений

REA анализировал только поставленные пакеты приложений. Это статический анализ: он показывает наличие кода и ресурсов, но не доказывает, что пользовательский сценарий работает в исполнении. Личные чаты, профиль, ключи, cookies и сетевой трафик пользователя не читались. Синтетический профиль для безопасного испытания конкурентов не создавался.

`CodexBar.app` имеет `com.steipete.codexbar`, версию `0.17.0`. Это иной продукт; его не подменяли Codex desktop. У Claude и Codex исходный ASAR объявляет контрольную сумму одного распакованного нативного модуля, которая не совпала с файлом. REA был запущен с `record-and-continue`: наблюдаемые байты этого участка считаются недоверенными. Это не доказывает взлом приложения и не делает его нативные части проверенными.

### Claude Desktop: конкретные находки REA

Обзор REA: SHA-256 `app.asar` `ce90267cb07b08d1e09c99be0e78abf39be2c06742a92367e54086b96f08caa3`; 648 релевантных файлов, 586 разобранных JavaScript-файлов, 14 статических созданий `BrowserWindow`, 56 наблюдений `contextBridge`. В пакете обнаружены отдельные модули `.vite/build/coworkArtifact.js`, `.vite/build/claudePagePreview.js` и поставленные библиотеки Chart.js 4.5.0, Grid.js 5.0.2, Mermaid 11.17.2. Модуль `claudePagePreview.js` подтверждён REA `ev_614dbaa09ad82fba41d5358cc92ae1ffd6eef8dfd1b579546629e9e75b4b2ff9`; модуль `coworkArtifact.js` — `ev_6ddb6e2e690a14ba3ec9973439adcf4834c7b32453747481ea0fbbcaed38c195`; выборка модулей — `ev_c565503601b3001cdf4d7d966f37fd9cd5c653fe469852d5a363ab303c2d3f22`. Трасса `coworkArtifact.js` — `ev_1099d061d3bc21b15a2362ed0ddb08912e5bb897aa00340391a78ba7792fa2a8`, неполная из-за неполного исходного графа. Отдельные названия и ресурсы не раскрывают всю модель изоляции и не подтверждают безопасность preview.

Предел REA: семантический граф частичный, часть больших модулей упёрлась в память и бюджет ответа. Его цифры — статистика анализа кода, не измерения памяти, скорости или работы продукта. Не следует переносить устройство Claude в наш клиент как готовое решение.

### Codex desktop: граница статического разбора

SHA-256 `app.asar` — `0c951258b7ab381ec601045ffb02159e53f424548dda18e6a4dcfd126557383b`. REA закончил инвентаризацию пакета, но полный результат превысил лимит передачи MCP. Сохранённая запись: `ev_180b8af1173afedf83e2b534e640736bb396fe63fdcda1722a6ada7a7e93ce77`. Полный JavaScript-граф превысил 300 секунд и не был сохранён. Не повторяя этот тяжёлый вызов, я адресно прочитал заголовок того же ASAR: 19 505 файловых записей; `package.json` называет пакет `openai-codex-electron`, версию `26.1029.61003` и entrypoint `.vite/build/early-bootstrap.js`; есть `.vite/build/preload.js` и `.vite/build/sandbox-preload.js`. Это подтверждает состав поставки, но не использование sandbox в каждом окне, не условия IPC и не поведение UI. REA-извлечение полного пакета тоже завершилось за лимитом передачи результата; его не использовали как свидетельство конкретной функции. Результат достаточен для идентичности и границы анализа, но не для восстановления архитектуры Codex.

## SimpleClaw: подтверждено документацией, не испытано платным запросом

- [Provider API](https://simple-claw.ru/docs/provider-api): `GET /v1/models` публичный; показаны `id`, `owned_by`, `display_name`, `pricing`. В показанной схеме нет окна контекста, токенизатора, всех свойств модели и подтверждения доступности по ключу.
- Тот же документ: `POST /v1/chat/completions` требует Bearer-ключ; документированы текстовые `messages`, `model`, `max_tokens` 1–32768, `temperature` 0–2, streaming и function tools. Финальный SSE-успех заявлен после учёта usage. Точная последовательность событий и поведение при обрыве из этой страницы не следуют.
- [Ошибки](https://simple-claw.ru/docs/errors): `429` различает квоту рублей, токеновую квоту, бюджет ключа и предоплаченный баланс; пример ошибки содержит `requestId`. Для `401`, `403`, `404` также есть разные коды.
- [Responses API](https://simple-claw.ru/docs/provider-api): описан как stateless; `previous_response_id` и файлы дают 400. Для первого релиза не нужен.
- Интерактивный OpenAPI по ссылке `/openapi` открылся как `/v1/docs`, но веб-инструмент не извлёк схему. `/docs/llms.txt` один раз показался текстовым ресурсом, повторное открытие завершилось ошибкой веб-инструмента. Публичный `/v1/models` тем же инструментом не открылся. Это граница доступа инструментов, не доказательство недоступности сервиса.
- В проверенных публичных страницах не найден контракт возобновления потока, идемпотентного ключа для платного POST, гарантии возврата usage после обрыва или значения списания при отмене. Отсутствие в просмотренных страницах не доказывает отсутствие функции на сервере. Нужен ответ SimpleClaw и управляемые испытания с отдельным лимитированным ключом.

## Платформенные факты

- [Tauri capabilities](https://v2.tauri.app/security/capabilities/) прямо предупреждает: собственные команды, зарегистрированные через `invoke_handler`, доступны всем окнам и webview по умолчанию. Для ограничений нужен `AppManifest::commands`; одинаково названные capability могут складывать разрешения. [Документация `tauri-build` 2.7.4](https://docs.rs/tauri-build/latest/tauri_build/struct.AppManifest.html) показывает генерацию `allow-$command` и `deny-$command`.
- [Tauri Channels](https://v2.tauri.app/develop/calling-frontend/) предназначены для упорядоченного потока; глобальные events не рассчитаны на большую пропускную способность и не имеют той же настройки прав.
- [Tauri WebView](https://v2.tauri.app/reference/webview-versions/): Windows использует WebView2, macOS — WebKit. Один тест на macOS не подтверждает поведение на Windows.
- [Стандарт HTML](https://html.spec.whatwg.org/multipage/iframe-embed-object.html#attr-iframe-sandbox): `allow-scripts` вместе с `allow-same-origin` у содержимого того же происхождения разрушает границу sandbox. Нужны ограничения также для сети и навигации.
- [Electron Security](https://www.electronjs.org/docs/latest/tutorial/security), [sandbox](https://www.electronjs.org/docs/latest/tutorial/sandbox), [MessagePorts](https://www.electronjs.org/docs/latest/tutorial/message-ports): Electron остаётся альтернативой, если проверка изоляции Tauri не пройдёт. [safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage) — шифрование строк средствами ОС; оно не тождественно хранению сырого секрета в Windows Credential Manager.
- [SQLite WAL](https://www.sqlite.org/wal.html) допускает одновременное чтение и запись с ограничениями; [Backup API](https://www.sqlite.org/backup.html) предназначен для согласованной резервной копии работающей БД.
