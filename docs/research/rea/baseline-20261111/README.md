## transformCallback: результат диагностики

В нативной `.app` исключение **не воспроизведено** при запуске, подписке уведомлений, предпросмотре контекста, mock-отправке, Retry, остановке, выборе вложения, открытии Artifact и повторном запуске. Минимальное исправление не внесено: подтверждённой причины нет.

Статический факт: `node_modules/@tauri-apps/api/core.js` в `transformCallback` обращается к `window.__TAURI_INTERNALS__.transformCallback`; конструктор `Channel` вызывает эту функцию. `src/main.tsx` создаёт Channel при отправке и регистрирует `onAction` при монтировании. Это места для дальнейшей диагностики, а не доказательство причины ошибки на исходном пользовательском снимке.

Открытие frontend в обычном браузере без моста Tauri — возможная гипотеза, **в этом прогоне не проверенная**. По снимку неизвестны URL, операция и стек исключения. Не следует маскировать эту неизвестность стилями или объявлять проблему исправленной. По условию задачи невоспроизводимость не блокирует переход к редизайну.

Windows, реальные платные ответы и расходы, системная смена темы, 200% масштаб, HTTP-обрыв и отрицательный viewer-сценарий этим прогоном не проверены. Живые исходные сценарии выше не закрывают старые задачи P0 или безопасность интерактивного viewer.
