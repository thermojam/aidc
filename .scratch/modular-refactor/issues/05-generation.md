# 05 — Поток ответа и повтор попытки

**What to build:** Выделить жизненный цикл ответа чата, сохранив историю, остановку и повтор попытки для обоих источников моделей.

**Blocked by:** 04 — Поле ввода чата.

**Status:** done

- [x] На macOS остановленный частичный ответ сохранился после перехода между беседами; устаревшие события проверены с подставным IPC.
- [x] Выбор исходных модели и провайдера при повторе проверен автоматическими тестами; прежняя ветка открыта в macOS. Смена источника в нативном UI не проверена: Ollama недоступна.
- [x] Подтверждение платного повтора и отсутствие автоматического повтора сохранены; отмена подтверждения проверена с подставным IPC, платный POST не выполнялся.
- [x] Rust-тесты проверяют разрезанные UTF-8 и JSON, несколько событий в порции, обрыв, отмену, последовательность и восстановление частичного ответа; пропуски отмечены в checks.md.
