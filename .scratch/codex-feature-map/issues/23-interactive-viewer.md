# 23 — Интерактивный HTML viewer

**What to build:** Пользователь запускает самодостаточную страницу в изолированном просмотрщике после испытаний на обеих ОС.

**Blocked by:** 02 — Завершить отрицательные проверки статического Preview; 05 — Испытать приложение на реальной Windows.

**Status:** blocked — depends on issues 02 and 05

- [ ] На WebKit и WebView2 пройдены отрицательные проверки IPC, сети, файлов, навигации, загрузок, буфера обмена и вложенных iframe.
- [ ] Зависший просмотрщик закрывается без падения чата; при любом провале обязательной проверки интерактивный режим остаётся выключенным.
