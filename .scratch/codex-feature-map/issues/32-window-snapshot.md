# 32 — Снимок выбранного окна

**What to build:** Пользователь делает снимок конкретного окна, просматривает его и решает, прикреплять ли к запросу.

**Blocked by:** None — can start immediately.

**Status:** implemented for macOS; live OS permission and viewer checks remain open

- [x] Разрешение ОС и выбор окна явные; скрытый или повторный захват не выполняется.
- [x] Снимок удаляется при отказе от прикрепления и не попадает в запрос без подтверждения.
- [ ] Проверить запуск selector, разрешение записи экрана и отказ от прикрепления в живом окне.
- [ ] Выполнить отрицательную проверку новых Tauri-команд из недоверенного viewer.
- [ ] Поддержка Windows не реализована; сначала нужен отдельный проверенный системный picker.
