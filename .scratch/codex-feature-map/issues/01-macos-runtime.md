# 01 — Проверить основные сценарии на macOS

**What to build:** Пользователь проходит ключевые сценарии в установленном приложении с отдельным тестовым профилем и синтетическими данными.

**Blocked by:** None — can start immediately.

**Status:** blocked — CUA lists the current app as running but cannot bind to it by bundle ID, path or name (`Invalid app`, `Running application not found`, timeout `-10005`)

- [ ] Сохранение и удаление ключа, выбор модели, несколько бесед, файлы и восстановление истории проверены нажатием в окне.
- [ ] Длинный ответ, ошибка, остановка потока, темы, фокус и клавиатурный маршрут проверены без платных запросов.
