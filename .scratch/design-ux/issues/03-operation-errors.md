# 03 — Показывать ошибки у соответствующей операции

**What to build:** Пользователь видит, что именно не получилось, что сохранено и каким действием восстановить работу, без общей красной строки для несвязанных ошибок.

**Blocked by:** 02 — Внедрить компоненты и темы через настройки внешнего вида.

**Status:** done — реализация и синтетический React UI проверены на macOS/Chromium 11 ноября 2026; нативные границы указаны в checks.md.

- [x] Ошибки каталога, отправки, вложения и данных привязаны к операции, беседе или попытке; обновление одной операции не стирает ошибку другой.
- [x] Каталог с кэшем и без него имеет разные сообщения и действие обновления; ошибка каталога не блокирует локальный тест. Нет ключа и 401 ведут к настройкам подключения.
- [x] Обрыв показан у конкретного ответа с сохранённым частичным текстом и неизвестным расходом; поздний результат старой операции не меняет текущую беседу или модель.
- [x] Сбой рендера ответа позволяет показать исходный текст; сбой рабочего экрана позволяет открыть его заново без удаления данных.
- [x] Подробности операции показывают время, код, HTTP-статус и request ID; копируется только безопасный набор без ключей, prompt, содержимого файлов и полных локальных путей.
- [x] Sonner показывает максимум три уведомления, объединяет повторы по операции; успех 4 с, фоновые предупреждения 8 с, критические до закрытия. Таймер приостановлен при hover/фокусе; фокус не захватывается.
- [x] Критическая ошибка имеет постоянное сообщение у места исправления. Отмена picker, остановка и SSE-дельты не создают toast; экранному диктору не объявляется весь поток.
- [x] В живом синтетическом сценарии проверены восстановление, две независимые ошибки и запоздалый результат; прошли проверка типов и сборка, результаты внесены в журнал.

Проверки: [журнал](../../../docs/research/rea/checks.md#редизайн-03-ошибки-операций--11-ноября-2026). Сценарии выполнены в отдельном синтетическом профиле Chrome с подменой IPC; это не проверка нативных picker, VoiceOver, WebKit или Windows. Платные запросы не выполнялись.
