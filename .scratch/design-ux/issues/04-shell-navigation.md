# 04 — Перестроить оболочку и навигацию проектов

**What to build:** Пользователь выбирает проект и беседу в постоянной навигации, а на узком окне открывает её по кнопке без потери доступных действий.

**Blocked by:** 02 — Внедрить компоненты и темы через настройки внешнего вида.

**Status:** implemented — проверки и ограничения macOS зафиксированы 13 ноября 2026 в `docs/research/rea/checks.md`.

- [x] Оболочка содержит док 48 px, навигацию по умолчанию 264 px с диапазоном 220–320 px и рабочую область с шапкой 48 px. Body не прокручивается; история и навигация прокручиваются независимо.
- [x] Действуют создание, переименование, архивирование, восстановление, закрепление, поиск и перенос бесед между существующими проектами; доступны беседы без проекта. Выбор проекта не даёт доступа к диску.
- [x] Есть проекты с вложенными беседами и до 10 недавних бесед как ссылки по ID; нет фиктивных Product/Information. Пустая история отличается от пустой поисковой выдачи.
- [x] Ширина, ручное скрытие и раскрытие сохраняются локально. При ≥1200 px навигация открыта по умолчанию; при 960–1199 первоначально скрыта и открывается только при центре ≥560 px.
- [x] При 640–959 px навигация открывается модальной панелью; при <640 док скрыт, вход в навигацию есть в шапке. Выбор закрывает панель, Escape и возврат фокуса работают; автосворачивание не стирает широкое предпочтение.
- [x] Меню и контекстное меню дают одинаковые действия; названия доступны целиком при фокусе, активность обозначена не одним цветом. Разделитель ширины имеет семантику separator и управляется стрелками.
- [x] Настройки и существующие инструменты остаются достижимы при постепенном переносе; переключение беседы во время потока остаётся запрещённым, существующее подтверждение удаления черновика сохраняется.
- [x] На macOS проверены мышь, клавиатура, 200% масштаб и основные размеры окна; прошли проверка типов и сборка, результаты внесены в журнал.

Нативная проверка охватила окно 1280×850 и эффективные ширины при 100/120/200/220% page zoom. Физическое перетаскивание границ, VoiceOver и Windows остаются непроверенными; весь набор действий отдельно проверен в Chromium с синтетическим IPC. Эти границы не считаются подтверждённым нативным прогоном каждого сценария.
