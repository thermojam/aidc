# 06 — Проверять подтверждённый состав запроса в Rust

**What to build:** Пользователь отправляет ровно тот состав запроса, который просмотрел и подтвердил; устаревший или отсутствующий результат проверки отклоняется до платной отправки.

**Blocked by:** None — can start immediately (нет блокирующих задач).

**Status:** implemented — macOS synthetic checks completed; real SimpleClaw and Windows not tested

- [x] Rust связывает успешный предпросмотр с точным составом и проверяет его при отправке; одного disabled-состояния кнопки или подписи в JS недостаточно.
- [x] Изменение текста, беседы, проекта, ветки, файлов/версий, модели, режима, стиля или действующих инструкций/параметров требует новой проверки. Запоздалый предпросмотр старого состава не разрешает отправку.
- [x] Проверка подтверждает реальные версии и содержимое, полномочия и ограничения Rust; переданный UI идентификатор не позволяет подменить проверенный состав.
- [x] Без проверки и при несовпадении состава попытка не запускается и POST не выполняется; пользователь получает понятное предложение проверить контекст заново.
- [x] Явное подтверждение платного запроса, неизвестного расхода и агентного режима сохранено. Retry остаётся отдельным действием с предупреждением и собственными действующими проверками, без автоматического POST.
- [x] Существующие Rust-тесты дополнены случаями отсутствующей, устаревшей и подменённой проверки и успешного неизменённого состава; применимые команды поимённо разрешены только main, отрицательный viewer-сценарий проверен.
- [x] Новый контракт зафиксирован в продуктовом ТЗ; прошли Rust-тесты, проверка типов и сборка. Сценарий выполнен на синтетическом профиле macOS без платных запросов и записан в журнал.


Проверки и границы записаны в `docs/research/rea/checks.md`, контракт — в `spec.md` (раздел «Редизайн 06»). 54 Rust-теста прошли, 2 штатно игнорируются; прошли typecheck/build и синтетический Chromium-сценарий. В отдельном macOS-профиле подтверждены отказ устаревшего контекста и успешный локальный ответ после новой проверки. Финальная `.app` собрана, viewer отклонил 52 проверяемых вызова. Повтор локального ответа в финальной сборке прерван недоступностью native pipe CUA; изменения изображений и области поиска проверены Rust-тестами. Платных вызовов не было.
