# 02 — Внедрить компоненты и темы через настройки внешнего вида

**What to build:** Пользователь меняет оформление в работающих настройках на новой компонентной базе, сохраняя действующие сценарии приложения.

**Blocked by:** 01 — Зафиксировать исходные сценарии и разобраться с transformCallback.

**Status:** done — компоненты и темы проверены на macOS 11 ноября 2026; итоговые проверки и ревью прошли.

- [x] Подключены Tailwind и только используемые Shadcn-компоненты одной совместимой семьи примитивов; версии и лицензии зафиксированы, посторонние зависимости не обновлены.
- [x] Настройки внешнего вида используют новые компоненты; закрытие возвращает фокус и сохраняет черновик. Остальной интерфейс остаётся работоспособным при постепенном переносе.
- [x] Смысловые роли цветов, размеры и типографика согласованы с дизайн-системой и новой UX-спецификацией; прежняя спецификация компактного чата явно обозначена как предыдущая стадия в затронутых решениях.
- [x] Светлая, тёмная и системная темы используют прежний ключ appearance. Проверены смена темы ОС, перезапуск и отсутствие вспышки неверной темы.
- [x] Измерен контраст текста ≥4,5:1, крупного текста ≥3:1, интерактивных границ и фокуса ≥3:1; focus ring виден. Декоративный разделитель не заменяет контур поля.
- [x] CSP не ослаблена ради компонентов; нет удалённых скриптов, внешних шрифтов и параллельной системы HEX-цветов.
- [x] На macOS прошли существующие проверка типов и сборка; настройка темы и клавиатура проверены в живом окне. Результаты записаны в журнал.
