# 15 — Перенести генерацию изображений в отдельное представление

**What to build:** Пользователь создаёт изображение в отдельном рабочем представлении с собственной моделью, подтверждением цены и сохранением результата.

**Blocked by:** 03 — Показывать ошибки у соответствующей операции; 04 — Перестроить оболочку и навигацию проектов.

**Status:** ready-for-agent

- [ ] Описание, собственный выбор модели, результат и сохранение доступны из дока; используются только модели с подтверждённым протоколом images_generations.
- [ ] До отправки показаны провайдер, модель, цена за запрос и дата каталога; неизвестная цена блокирует отправку, Rust повторно сверяет тариф перед POST.
- [ ] Переход в чат и обратно сохраняет описание, результат и состояние выполняемой операции; состояние запрета повтора неопределённого исхода не сбрасывается переключением представлений.
- [ ] Подтверждение, отмена и ошибка не запускают повторный POST; та же комбинация модели/описания после неизвестного исхода остаётся заблокированной по действующему контракту.
- [ ] Синтетический PNG отображается и сохраняется через системный диалог; отмена сохранения и отказ записи имеют корректный результат, успех не показывается заранее.
- [ ] На macOS проверены клавиатура, переходы, неизвестная/изменившаяся цена и сохранение без платной генерации; ключ остаётся только в Rust и системном хранилище.
- [ ] Прошли проверка типов и сборка, при изменении Rust — существующие тесты. Результаты внесены в журнал с явной границей: успешная платная генерация не подтверждена.
