# 17 — Выбирать материалы через @mentions

**What to build:** Пользователь выбирает доступный материал по имени в поле сообщения и видит его как явный источник следующего контекста.

**Blocked by:** 05 — Вынести материалы проекта в отдельное представление; 07 — Собрать компактный ввод с проверкой и отправкой.

**Status:** ready-for-agent

- [ ] «@» в начале или после пробела открывает только материалы текущего проекта; вне проекта доступны лишь уже выбранные вложения. Нет скрытого чтения папок или диска.
- [ ] Строка содержит имя, доступный относительный путь и тип без выдуманных метаданных. Поиск, до восьми видимых строк, стрелки, Enter, Tab, Escape и aria-activedescendant работают как в контракте подсказок.
- [ ] Textarea сохранена; выбранный ресурс хранится отдельным чипом с ID конкретной версии, текстовая ссылка не является полномочием на чтение. Email без явного выбора не становится mention.
- [ ] Удаление чипа исключает материал из контекста; выбор сбрасывает подтверждение, повторное упоминание не дублирует ресурс и не обходит общий лимит вложений.
- [ ] Пустая выдача показывает «Нет доступных материалов» и доступный выбор файла; раздел агентов отсутствует без реестра.
- [ ] Выбор не отправляет сообщение, Escape сохраняет текст, IME не запускает отправку. Предпросмотр и Rust используют ту же версию и ограничения, что обычный выбор материала.
- [ ] На macOS проверены материал проекта, вложение без проекта, удаление, email, пустая выдача и недоступный ID; прошли проверка типов и сборка, при изменении Rust — существующие тесты. Результаты внесены в журнал.
