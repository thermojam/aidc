# 08 — Добавить поиск моделей и параметры запроса

**What to build:** Пользователь быстро находит модель, понимает её подтверждённые возможности и выбирает режим следующего запроса.

**Blocked by:** 07 — Собрать компактный ввод с проверкой и отправкой.

**Status:** implemented — macOS-срез проверен; границы в checks.md

- [ ] Выбор модели открывает доступный с клавиатуры popover с поиском, категориями, реальным именем, провайдером и состоянием; избранные модели идут первыми и сохраняются после перезапуска.
- [ ] Пользовательские категории сохраняются при обновлении каталога; локальный тест остаётся доступен при ошибке сети.
- [ ] Показаны источник и дата цены, устаревший кэш, неизвестный лимит контекста и неизвестный расход. Нет ложного процента заполнения или индикатора готовности POST по успешному каталогу.
- [ ] Параметры содержат явный режим «Чат / Агент», активный агент обозначен постоянным чипом; поддержка ограничена действующим контрактом, новые полномочия не выдаются.
- [ ] Reasoning-параметры не показываются без подтверждённой поддержки. Реальные model ID не заменены надписями из референсов.
- [ ] Выбор сбрасывает проверку контекста; параметры активной попытки неизменны. Длинное имя не выталкивает отправку на узком окне.
- [ ] На macOS проверены поиск, клавиатура, сохранение избранного, недоступный каталог и неизвестные свойства; прошли проверка типов и сборка, при изменениях Rust/БД — существующие тесты. Новый контракт сохранения избранного и результаты зафиксированы.
