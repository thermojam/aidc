# 10 — Добавлять файлы перетаскиванием

**What to build:** Пользователь перетаскивает файлы в чат, видит результат проверки каждого файла и добавляет их в состав следующего сообщения без отправки.

**Blocked by:** 07 — Собрать компактный ввод с проверкой и отправкой.

**Status:** ready-for-agent

- [ ] Используются события Tauri существующего webview; нет параллельных HTML/Tauri обработчиков с дублями, подписка освобождается при unmount.
- [ ] При входе файлов видны рамка и текст «Добавить файлы в сообщение»; уход и завершение drop снимают подсветку. Drop в навигацию не перемещает и не удаляет файлы.
- [ ] Чтение, канонизация пути, кодировка, размеры, форматы и секретные имена проверяются Rust тем же путём, что picker; состояния loading/ready/rejected и причины отказа видны поимённо.
- [ ] Дубли определяются действующим контрактом идентичности вложения, а не одним именем; лимиты количества и размера одинаковы для picker и drop.
- [ ] Папка не обходится: пользователь получает объяснение выбрать отдельные файлы. Drop не выдаёт произвольный доступ к диску, не отправляет POST и сбрасывает проверку состава при изменении выбора.
- [ ] В синтетическом macOS-сценарии проверены допустимый файл, два одноимённых файла, дубль, секретный/слишком большой файл, папка и повторный mount без повторной обработки.
- [ ] Прошли проверка типов, сборка и существующие Rust-тесты при изменении файлового пути; новые команды разрешены только main, отказ viewer проверен. Контракт и результаты внесены в документы.
