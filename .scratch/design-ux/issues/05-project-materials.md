# 05 — Вынести материалы проекта в отдельное представление

**What to build:** Пользователь управляет материалами проекта отдельно от переписки и явно выбирает версии, которые войдут в следующий запрос.

**Blocked by:** 04 — Перестроить оболочку и навигацию проектов.

**Status:** implemented — проверки и границы macOS зафиксированы 13 ноября 2026 в `docs/research/rea/checks.md`.

- [x] Библиотека и выбранная папка доступны из проекта; просмотр не очищает черновик, вложения и выбор версий. Возврат восстанавливает рабочую беседу.
- [x] Сохраняются добавление материала, история неизменяемых версий, SHA-256, размер и полный предпросмотр; новая версия не меняет уже отправленный контекст.
- [x] Явный выбор материалов отражён у ввода и в точном составе запроса; общий существующий предел пяти выбранных файлов/версий не обходится.
- [x] Подключённая папка показывает только разрешённый первый уровень с существующими пределами и причинами блокировки; предпросмотр и добавление проверяют изменение исходника.
- [x] Архивный или чужой проект не предоставляет материалы текущей беседе; выбор проекта не запускает обход диска и автоматическую отправку.
- [x] В живом macOS-окне проверены выбор версии, возврат к черновику, изменение исходного файла и недоступный материал. Прошли проверка типов и сборка; при изменении Rust/БД — соответствующие существующие тесты. Результаты внесены в журнал.

Нативно проверены версии, возврат к черновику, изменение и исчезновение исходника, отказ viewer. Общий предел пяти файлов и точные ID контекста дополнительно проверены в Chromium с синтетическим IPC; полного нативного прогона этих сочетаний и Windows не было.
