# 07 — Собрать компактный ввод с проверкой и отправкой

**What to build:** Пользователь пишет сообщение, видит выбранный контекст, проверяет состав и явно отправляет запрос из одного компактного блока.

**Blocked by:** 04 — Перестроить оболочку и навигацию проектов; 06 — Проверять подтверждённый состав запроса в Rust.

**Status:** implemented — частичная macOS-приёмка; остаток в checks.md

- [ ] Textarea имеет доступную метку, минимум две строки, рост до восьми строк или 240 px и внутреннюю прокрутку; лимит 2000 символов сохранён, счётчик появляется с 80%.
- [ ] Ввод и история ограничены шириной до 800 px; composer расположен отдельной строкой сетки и не перекрывает ответ. При высоте <700 px он занимает максимум 35% доступной высоты.
- [ ] Видны проект, модель, меню «+», «Проверить контекст» и текстовая отправка/остановка. Чипы занимают до двух строк, затем «Ещё N» с полным списком и предпросмотром.
- [ ] Редкие настройки раскрываются по действию; материалы не перечисляются постоянно под вводом. Метка «Этот компьютер» не создаёт впечатления локального исполнения сетевой модели.
- [ ] Enter отправляет только актуальный подтверждённый состав; иначе переводит к проверке с пояснением. Shift+Enter добавляет строку; IME-композиция и Enter в списке подсказок не отправляют запрос.
- [ ] При потоке можно писать следующий черновик, он не отправляется автоматически и не теряется при завершении или ошибке текущего ответа. Остановка сохраняет частичный текст.
- [ ] Любое изменение состава сбрасывает проверку; неизвестный расход остаётся видимым. Локальный тест явно помечен «без сети».
- [ ] На macOS пройден путь модель → файл → проверка → отправка → остановка с клавиатуры и mock-потоком; прошли проверка типов и сборка, результаты внесены в журнал.
