# 20 — Интегрировать titlebar на macOS

**What to build:** Пользователь управляет окном macOS через нативные кнопки и свободную область интегрированного заголовка без конфликтов с элементами интерфейса.

**Blocked by:** 18 — Принять основной редизайн на macOS.

**Status:** ready-for-agent

- [ ] Это отдельный срез после основной приёмки. До него сохраняются нативные декорации; реализация Windows не включена в эту задачу.
- [ ] Сохранены нативные traffic lights; DOM-кнопки их не имитируют. Безопасная область слева не менее 80 px проверена в фактическом окне, активном/неактивном состоянии и fullscreen.
- [ ] Drag-region действует только на свободной области, не на кнопках, селекторах, полях и вкладках; проверены двойной клик, resize, перетаскивание неактивного окна и смена монитора.
- [ ] Настройки, навигация, поиск и Artifact доступны с клавиатуры; focus ring, tooltip и уведомления не перекрываются заголовком.
- [ ] Закрытие во время mock-потока не создаёт повторный POST; после запуска показаны сохранённый частичный ответ и прерванная попытка согласно действующему Rust-контракту.
- [ ] Новые оконные полномочия выдаются поимённо только main; отрицательный вызов из viewer отклонён по правам.
- [ ] Прошли проверка типов, сборка, применимые Rust-тесты и живой сценарий macOS; результаты записаны, Windows/Snap/DPI остаются отдельной непроверенной стадией.
