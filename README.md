# AI Desktop Client

Локальный десктопный клиент чата на Tauri 2, Rust и React. Сейчас приложение поддерживает несколько бесед, ветки ответов, локальную историю SQLite, системное хранение ключа, каталог моделей, выбранные текстовые вложения и просмотр Artifacts в виде кода или статического Preview.

## Статус

Проект в разработке. Реальный запрос к SimpleClaw ещё не входит в подтверждённый сценарий работы; не считайте текущую сборку готовым клиентом для платных запросов. Интерактивный просмотр HTML/SVG отключён. Состояние проверок, известные ограничения и результаты запусков описаны в [журнале проверок](docs/research/rea/checks.md), требования к первому релизу — в [спецификации](docs/research/rea/spec.md).

Проверено на macOS: отдельные срезы интерфейса, SQLite, вложений, каталога моделей, статического Preview и нескольких бесед. Проверка приложения на Windows и часть сценариев в запущенной macOS-сборке остаются открытыми. Уточняйте конкретные результаты в журнале проверок.

## Требования

- Node.js 22 или новее
- Rust stable
- Системные зависимости Tauri 2 для вашей ОС: [инструкция установки](https://v2.tauri.app/start/prerequisites/)

## Запуск и проверки

```sh
npm ci
npm run typecheck
npm run build
cd src-tauri && cargo test
cd ..
npm run tauri dev
```

Чтобы собрать macOS-приложение:

```sh
npm run tauri build -- --bundles app
```

Тестовое окно `viewer` для проверки прав команд запускается с отдельной конфигурацией:

```sh
npm run tauri dev -- --config src-tauri/tauri.viewer-test.conf.json
```

Windows проверяйте на реальной машине по [сценарию smoke-теста](docs/research/rea/smoke-windows.md). Сборка одной платформы не подтверждает работу другой.

## Безопасность и границы

Ключ приложения хранится в системном хранилище и используется в Rust. Тестовый `viewer` добавляется только отдельной конфигурацией. Вложения выбираются явно, проверяются до отправки и сохраняются как снимки в локальной истории. Preview показывает статическое содержимое; он не исполняет код Artifacts.

Не добавляйте ключи в исходники, SQLite, логи или параметры запуска. `.env` предназначен только для ручных проверок и не является источником ключа приложения. Не отправляйте платные запросы без отдельного разрешения на конкретный расход.
